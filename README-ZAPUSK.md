# Соционика: тренажёр — как запустить на своём компьютере

Твой **второй** учебный проект: викторина-тренажёр по соционике на Next.js + React.

## Что нужно заранее

**Node.js версии 20 или новее.** Проверь в терминале:

```powershell
node -v
```

Если нет или версия старая — скачай LTS с https://nodejs.org и установи.

## Запуск за 4 шага

1. **Распакуй архив** в папку `Documents` (правый клик → «Извлечь всё...»).
2. **Открой терминал в папке** `socionika`: Проводник → клик в адресную строку → напиши `powershell` → Enter.
3. **Установи библиотеки** (один раз):
   ```powershell
   npm install
   ```
4. **Запусти игру:**
   ```powershell
   npm run dev
   ```
   Открой в браузере **http://localhost:3000** — тренируйся!

Остановить сервер: **Ctrl+C**. При следующем запуске: зайти в папку → `npm run dev` (install больше не нужен).

```
socionika/
├── package.json            ← библиотеки и команды (всего 3! проще, чем у Сапёра)
├── next.config.ts          ← настройки Next.js
└── src/
    ├── app/
    │   ├── page.tsx        ← ИНТЕРФЕЙС: экраны «темы → вопросы → результат» и глоссарий
    │   ├── layout.tsx      ← оболочка страницы
    │   └── globals.css     ← стили
    └── lib/
        ├── socionics-data.ts  ← ДАННЫЕ: 16 типов, 8 функций, квадры, дихотомии
        └── socionics-quiz.ts  ← ЛОГИКА: модель А, формулы отношений, генератор вопросов
```

## Чем этот проект отличается от Сапёра (что ты узнаешь нового)

- **Отдельные файлы данных** (`socionics-data.ts`) — как словарь Python: много фактов, ноль логики
- **Вычисление вместо таблиц**: отношения между типами и модель А считаются формулами из букв типа — смотри функции `dualOf`, `modelA` в `socionics-quiz.ts`
- **Генератор вопросов**: вопросы создаются кодом из данных, а не пишутся вручную
- **localStorage для рекордов** — тот же приём, что и в Сапёре

Проверить факты и логику можно командой (если поставишь Bun) или просто читаешь тесты:
`scripts`-подход описан в методичке, глава 6.
